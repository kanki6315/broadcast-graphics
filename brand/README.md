# Gantry brand assets

The canonical mark is a circular `G` interrupted by a centered timing beam and a separated orange sensor. Its geometry is shared by every derivative in this folder.

## Palette

- Carbon ink: `#15191c`
- Approval orange: `#ff4b21`
- Technical stock: `#f4f1e8`

## Files

- `gantry-mark.svg`: primary two-color symbol with a transparent background.
- `gantry-mark-mono.svg`: one-color symbol for constrained reproduction.
- `gantry-lockup-horizontal.svg`: primary horizontal lockup.
- `gantry-lockup-stacked.svg`: stacked lockup matching the approved exploration.
- `gantry-mark-512.png`: transparent high-resolution symbol.
- `gantry-lockup-horizontal-1600.png`: transparent horizontal raster lockup.
- `gantry-lockup-stacked-1200.png`: transparent stacked raster lockup.

The lockups use the included Barlow Condensed Bold font. Preserve the mark proportions, the gap before the orange sensor, and the supplied colors. Do not add speed lines, gradients, shadows, outlines, or automotive imagery.
